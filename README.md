# اقتصاديات الذكاء الاصطناعي والوكلاء

Economics of AI and Agents

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-EXE-202 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يحسب المشاركون تكلفة الذكاء الاصطناعي بالطريقة التي يُفوتَر بها ويُستخدم فعلًا. فانطلاقًا من 50 تشغيلًا موسومًا لمسار عمل وكيلي مستضاف، يحسبون التكلفة لكل مهمة ناجحة بوصفها توزيعًا، ويسعّرونها وفق نظم التسعير بالوحدات النصية وبالسعة وبالنتيجة، ويقيسون الروافع التي تغيّر التكلفة والجودة، ويكتبون خطة لحوكمة التكاليف.

**الصيغة:** ورشة عمل: يوم ونصف مع مختبرات ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-exe-202/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يشرح لماذا تتجاوز الوحدات النصية (tokens) المفوترة مدخلات المستخدم، ولماذا يعطي السعر لكل وحدة نصية صورة خاطئة عن تكلفة مسار العمل، استنادًا إلى سجل الوحدات النصية لتشغيل واحد لوكيل | Awareness | السجل مشروحًا بحسب التعليمات والسجل السابق للمحادثة والاسترجاع والاستدلال وإعادة المحاولة |
| LO2 | يحسب التكلفة لكل مهمة ناجحة، بما في ذلك إعادة المحاولة والتشغيلات الفاشلة ووقت المراجعة البشرية، على مجموعة من 50 تشغيلًا موسومًا | Applied | الوسيط والمئين التسعون والمتوسط، مع المعادلات |
| LO3 | يقارن بين التسعير بالوحدات النصية وبالسعة وبالمستخدم أو بالنتيجة لمسار عمل واحد عند ثلاثة أحجام استخدام، استنادًا إلى ثلاث قوائم أسعار | Applied | أحجام التعادل والخيار المختار لكل حجم |
| LO4 | يقيس أثر توجيه النماذج والتخزين المؤقت وتقصير السياق وتقليل إعادة المحاولة في التكلفة ونسبة النجاح، استنادًا إلى إعادة تشغيل مع تطبيق رافعتين | Applied | جدول روافع بالتغيرات المقيسة |
| LO5 | يصمم خطة لحوكمة التكاليف فيها مؤشرات لتكلفة الوحدة وموازنات وتنبيهات وصلاحيات قرار، استنادًا إلى بيانات إنفاق اصطناعية | Performance | خطة من صفحتين يدافع عنها في المراجعة |
