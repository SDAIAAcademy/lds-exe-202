# اقتصاديات الذكاء الاصطناعي والوكلاء · المختبرات

أربعة مختبرات لمقرر أكاديمية سدايا **LDS-EXE-202**. المختبرات صفحات إرشادية بالعربية تُعمل في جدول بيانات: الهدف، والملفات، والخطوات بدقائقها، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرّب. لا كود يكتبه المشارك.

كل المختبرات في جهة واحدة: **مكتب البيانات المفتوحة في هيئة تطوير مدينة الأقحوان**، هيئة افتراضية لمدينة افتراضية. كل الأسماء والأرقام مخترعة، وكل الملفات مصنفة «عام».

## «واصِف» ليس نموذجًا

«واصِف» وكيل يُعدّ حزم نشر لمجموعات بيانات «عامة». في هذا المقرر هو برنامج مكتوب السلوك بسحبات عشوائية ثابتة (`_tools/wasif_sim.mjs`) يقلّد حلقة الوكيل: خطة، فأدوات، فاسترجاع، فمسودات، فتحقق، فإعادة محاولة. يعطي القاعة كلها الأرقام نفسها. أثر كل رافعة فيه افتراض اصطناعي صممه المقرر، لا قياس لنموذج أو مزوّد حقيقي. ولم يُستدعَ أي نموذج مستضاف في بناء المقرر.

## ما يحتاجه المشارك

- جدول بيانات: LibreOffice Calc أو Microsoft Excel. المعادلات المستعملة: `SUMIF` و`COUNTIFS` و`MEDIAN` و`PERCENTILE.INC` و`CEILING`.
- متصفح للمختبر 2.1.
- لا حساب ولا مفتاح. المهمة الإضافية في 1.1 وحدها تستعمل حساب المشارك في خدمة نموذج مستضاف إن كان لديه، ببيانات «عامة» فقط.

## للمدرّب: المفتاح والأدوات

- `solutions/answer_key.md`: كل ما زُرع في الملفات، وأين، وأي مختبر يكشفه.
- `solutions/key.json`: الأرقام المرجعية كلها، يكتبها المولّد.
- `solutions/check_all.mjs`: يتحقق أن المولّد يكتب البايتات نفسها، ويعيد حساب كل رقم مرجعي من ملفات CSV بطريقة جدول البيانات، ويشغّل صفحة المُشغِّل في بيئة معزولة ويقارن ما تنزّله بالسجلات الجاهزة. يطبع PASS أو أول اختلاف.

الأدوات بلغة JavaScript ولا تحتاج غير Node 22 أو أحدث، وتُشغَّل من جذر المستودع:

```
node labs/_tools/prepare_files.mjs
node labs/solutions/check_all.mjs
```

الأول يعيد كتابة `files/` و`tools/rerun.html` و`solutions/key.json`. مع `--check` لا يكتب شيئًا ويقارن فقط.
